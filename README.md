Sou designer UI/UX, com foco em experiência do usuário. Meu trabalho é criar interfaces claras e pensar nos detalhes que tornam um produto mais simples de usar.

### O que eu faço

- **Descoberta** — entendo o problema, o contexto e quem vai usar antes de desenhar qualquer tela
- **Fluxos e wireframes** — organizo a navegação e a estrutura antes de pensar no visual
- **Interface (UI)** — telas consistentes, legíveis e prontas para o desenvolvimento
- **Protótipos** — versões navegáveis para testar decisões antes de construir
- **Design System** — componentes e padrões que mantêm o produto coerente conforme ele cresce

### Como eu trabalho

Começo pelo problema, não pela tela. Valido cedo, testo com quem vai usar e mantenho as decisões documentadas — assim o time inteiro entende o porquê de cada escolha.
